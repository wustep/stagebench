# Fonts

`crimson-pro-latin-wght-normal.woff2`: **Crimson Pro**, the variable upright (weights 200–900), Latin subset, as published by Fontsource in `@fontsource-variable/crimson-pro` 5.2.8. Copyright 2018 The Crimson Pro Project Authors (https://github.com/Fonthausen/CrimsonPro). Licensed under the SIL Open Font License 1.1, in `OFL.txt` next to it.

It's the serif for the end card's "StageBench" title (the heading face of wustep.me). `scripts/compose.mjs` embeds it with `@font-face`, and checks that it is the face that rendered. Every other piece of type is SF Pro through `-apple-system`.
