# Nord Stage 4 73 — Stagebench Phase 2

An interactive Nord Stage 4 73 in the browser. In this phase the **Piano** section, the
**Layer Effects** section, the **Rotary Speaker**, and **Master Level** are functional.
Organ, Synth, and Program controls move or press but are decorative.

```sh
pnpm install
pnpm dev        # develop
pnpm test       # 21 test files, 366 tests, deterministic, no devices or network
pnpm typecheck
pnpm lint
pnpm build      # writes dist/index.html and dist/samples/
pnpm preview    # serve the build (audio and samples need http://, not file://)
```

## Playing

- Mouse or touch on the keys. Striking nearer the front edge is harder. Slide for a glissando.
- Computer keys `A W S E D F T G Y H U J K O L P ; '` (C4 upward). `Z` / `X` shift the octave.
- `Space` is the sustain pedal unless a control has focus; there is also an on-screen pedal.
- MIDI keyboard: press **Enable MIDI**. Notes, velocity, and sustain (CC64) are supported.

## The Piano section

- **Type** steps through Grand, Upright, Electric, Clav, Digital, Misc. The **Model dial** chooses
  within a type (Clav and Misc have two models). The Program display names the model and says
  whether it is *recorded samples* or *synthesized*.
- **Layer A / Layer B**: a press turns an off layer on and focuses it, focuses an on layer, or turns
  the focused layer off. Faders set each layer's level. With both on, the focused layer's LED blinks.
  The other Piano controls edit the focused layer.
- **Octave Shift**, **KB Touch**, **Dyn Comp**, **Timbre**, **Unison**, **Acoustics** (Soft Release,
  String Res) all change the sound of the focused layer.
- **Shift + Layer A** is SUSTPED (the sustain pedal reaches the Piano). **Shift + Layer B** is PSTICK
  (the pitch stick bends the Piano ±2 semitones).

**Shift** means: hold a panel Shift button (touch or keyboard), or hold the computer's Shift key,
or click a panel Shift button once to latch it for the next control.

## Layer Effects

Each Piano layer has its own chain, in this order:
Mod 1 → Mod 2 → Delay → Amp Sim/EQ → Compressor → Reverb → (Rotary) → layer level → master.

- The effect controls show and edit the chain of the layer in **FX Focus**. Focus follows the Piano
  layer buttons; the **FX Focus Piano** button moves it by hand. **Shift + FX Focus Piano** is Group
  (both layers share one setting).
- Each unit has an **On** button. **Layer Effects On** bypasses everything at once.
- **Shift + On** on Delay, Compressor, or Reverb makes that unit Global.
- Delay: **Tap** twice to set the tempo; **Filter** steps Off / LP / BP / HP; **Shift + Filter** is Ping Pong.
- Compressor: turn **Amount** with Shift held for Fast mode.
- Amp Sim/EQ: the selector reaches Twin, JC, Small, To Rotary, LP Filter, HP Filter, and a seventh
  position with no LED lit, which is the plain EQ. **To Rotary** sends the layer through the Rotary
  Speaker (Slow/Fast, Stop Mode, Drive, at the far left).

Every unit starts off, so the instrument starts as a plain piano.

## Samples and licences

Grand, Upright, and Electric are recordings bundled in `public/samples/` (198 FLAC files, 12 MB):

| Type | Source | Licence |
| --- | --- | --- |
| Grand | Salamander Grand Piano V3 (Yamaha C5), Alexander Holm | CC BY 3.0 |
| Upright | Upright Piano KW (Kawai), FreePats — Gonzalo and Roberto | CC0 1.0 |
| Electric | Wurlitzer EP200 Electric Piano v1.1, Greg Sullivan | CC BY 3.0 |

Each folder carries its `LICENSE.txt`. `scripts/build-samples.mjs` is the exact recipe that produced
the files from pinned upstream commits; `IMPLEMENTATION_DETAILS.json` lists every file. Clav,
Digital, Misc, and the fallback piano are synthesized by this app and are not recordings.

If a sample set cannot be loaded, that piano is replaced by a synthesized stand-in labelled
**Fallback Synth Piano**, its type LED flashes, and the audio status reads *Fallback*.
