# Phase 2 audio verification

`tests/stage2-audio-browser.mjs` was run in Chromium against the local Vite server using OfflineAudioContext and the actual decoded bundled recordings and effect nodes. The six types produced distinct non-silent signals at middle C. In the final pass Grand/Upright/Electric/Clav/Digital/Misc RMS values over the first half-second were approximately 0.0194/0.0305/0.0393/0.0292/0.0557/0.0152. A softer Grand stroke measured 0.0059; zero master gain produced silence.

The test checks the six Mod 1 and Mod 2 types, six amp/filter colors, rotary, six reverb responses, effect bypass and amount/rate/drive changes, EQ, compressor and reverb controls, and delay feedback filtering. A dry impulse produced no repeat; the wet first and second repeat peaks were about 0.594 and 0.322, with low-pass feedback reducing the second to 0.081. Full-graph tests inspect the actual node connections, including reverb before rotary and the delay feedback filter, and exercise all-effects bypass, two-layer output and per-layer sustain, including return of voice and pitch-parameter counts to zero after release. A forced sample fetch failure verifies a labeled playable fallback. A live context close check verifies the context closes and owned voice counts return to zero.

The inherited Phase 1 browser audio relationships were also checked using its existing test body with the Vite source import: the loud early signal exceeded the soft signal, and pedal-held tail exceeded the released tail. Browser audio tests are run separately from `pnpm test`; the latter runs the Vitest suite. These tests use tolerant relationships and do not claim waveform identity across browsers.
