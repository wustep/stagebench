# Stage 1 Visual Audit

Target: Nord Stage 4 73 (`stage-4-73`) from `inputs/reference/nord-stage-4-73.jpg`.

Measured source reference from `nord-stage-4.variants.json`:

- Source canvas: 11600 x 3866.
- Instrument bounds: x 1292, y 410, width 9013, height 2912.
- Instrument aspect ratio: 3.0951.
- Keyboard: 73 total keys, 43 white, 30 black, E1 to E7, hammer action, black key height fraction 0.61.

Implemented bounds and ratios:

- `.instrument-shell` uses `aspect-ratio: 3.0951`.
- Desktop sizing target is `min(94vw, (100vh - 96px) * 3.0951)`, which is 1353.6 px wide at 1440 x 900: 94.0% of viewport width, inside the required 88-97% interval.
- Narrow sizing target is 96vw at 390 x 844: 374.4 px wide, with no intended clipping and the entire instrument kept inspectable in the first viewport.
- Deck/keybed allocation uses shell rows of 6% top rail, 48% control deck, 41% keybed, 5% bottom rail. The control deck plus top rail is 54%, and keybed plus bottom rail is 46%.
- Section widths are rendered from the documented fractions: Performance 13%, Organ 21%, Piano 15%, Program/Morph 9%, Synth 21%, Layer Effects 21%.

Inventory checks:

- Program and Synth are the only primary OLED displays.
- Organ includes nine physical drawbars and LED ladders.
- Piano includes layer faders, layer buttons, type buttons, model encoder, KB Touch, Timbre, Soft Release, and String Res controls.
- Program includes a display, large dial, eight program buttons, page controls, Live, Scene, Store, Split, and three Morph assignment buttons.
- Synth includes one OLED, layer controls, source buttons, oscillator/filter/envelope/LFO/arpeggiator controls.
- Effects includes layer focus controls and grouped modulation, delay, amp/EQ, compressor, reverb, and rotary controls.

Interaction audit:

- Keybed pointer down/up/cancel/lost-capture depresses and releases keys.
- Independent pointer IDs are tracked so multi-touch releases do not clear unrelated notes.
- Computer keys map to a central playable range and suppress repeat events.
- Spacebar is a sustain input; Web MIDI note on/off and CC64 sustain route through the same piano lifecycle when available.
- Blur, MIDI disconnect/state change, and unmount call all-notes-off cleanup.
- Decorative controls have stable `data-control-id` values, accessible names, keyboard operation, visible focus, and visible state changes.

Known deviations:

- The Phase 1 piano is generated live synthesis, not a recorded Nord or acoustic piano sample. This is declared in `IMPLEMENTATION_DETAILS.json`.
- Panel controls are intentionally decorative in Phase 1. Displays label unimplemented Synth behavior as decorative, and the status strip states that panel controls are decorative.
- The rendered surface approximates label density and physical grouping from the product photo; it does not reproduce every tiny printed legend from the original hardware.
- Canonical `stage1-desktop.png`, `stage1-narrow.png`, and `stage1-capture.json` are generated by the parent-controlled `pnpm bench seal gpt5-5-high-2` capture harness after build import.
