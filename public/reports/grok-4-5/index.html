  2. critical Program Store never captures engine edits, and morphs never reach audio: state/control-bindings.ts defines syncEngineToProgram() but references it only as the statement `void syncEngineToProgram` (line 1004), so nothing a piano/organ/synth/effects control touches ever enters programStore.working.   3. critical All 54 bundled sample WAVs are malformed; the build always runs the fallback voice: scripts/generate-samples.mjs writes the channel count at byte offset 21 instead of 22 (`buf.writeUInt16LE(1, 21)`), so every file has audioFormat 257 and numChannels 0.   4. major Deck gets 0.476 of the chassis instead of 0.54 because an inline flex overrides the stylesheet: ControlDeck.tsx renders style={{flex: SECTION_LAYOUT.length}} on .control-deck, and that shorthand beats the stylesheet's `flex: 0 0 calc(var(--deck-frac) * 100%)`. getComputedStyle returns flex-basis 0% / flex-grow 6 for the deck against flex-basis 46% / flex-grow 0 for the keybed, so the deck receives leftover space only: 201.17 px + 6.95 px top rail = 0.4759 of the 437.33 px chassis.
