  • Vox and Pipe1 are one engine: DC-removed spectral cosine 0.9993, AC-RMS 0.049242 vs 0.049213, DC 0.13303 vs 0.13471. Only Farfisa is separable (cosine 0.38-0.45 against the others).
  • Percussion and vibrato barely move the signal: percussion on gave spectral cosine 0.9614 with RMS 0.14363 vs 0.14396 off; vibrato on 0.9536, vibrato chorus at maximum 0.9267. Rotary produced no modulation at all (envelope mod depth 0.133 vs 0.134) and cannot be routed from the panel.
  • Changing the organ model a second time in a session poisons the whole output with NaN permanently (program 4 -> Vox -> Pipe: 20480/20480 NaN samples; also Farf -> Pipe). There is no Organ Section On or layer A/B switch on the panel, so the organ can only be enabled by recalling a program.
Synth system 0/4 0
  • The oscillator waveform selector does nothing to the sound. Stepping through all ten positions moved the synth OLED through 'Super 0/0', 'Pure 1/0'..'Pure 6/0', 'Sync 1/0', 'Sync 0/0' while the DC-removed render stayed at AC-RMS 0.018876 with consecutive spectral cosine 1.0000 at every step.
  • The amplitude envelope is not applied: on '4.1 Synth Pad' (attack 0.3 s, release 0.6 s) the 10 ms envelope of the note is flat from the first frame (0.01881, 0.01839, 0.01911, 0.01981, ... over 0.6 s) and the release tail holds full level then hard-cuts. Setting Envelope attack to maximum changed nothing measurable.
  • The synth parks the shared bus at a constant -0.372 DC offset even with no note held (DC -0.37209, AC-RMS 0.00059), which is 20x the audible AC content of the note and consumes 37% of the headroom before the limiter.
  • Two synth paths NaN the instrument permanently: holding a three-note chord (z+c+g) on a synth program produced 28672/28672 NaN samples, and setting Filter cutoff to maximum did the same. Neither Panic nor a program change recovers.
  • The filter type selector (synth.filter-type, LP12/LP24/HP/BP) is not bound in bridge.ts, and only synth layer 1 has any parameter bindings — S2 and S3 expose level only. Cutoff and resonance do move the signal slightly (spectral cosine 0.986 and 0.983 against default) and the LFO does modulate (cosine 0.335), which are the only synth controls I could measure as effective.
Layers, splits, scenes & morphs 1/4 25
  • Splits are the strongest part: zone routing measured across engines on '5.1 Split' (MIDI 60 = piano only at RMS 0.0188; split off = piano + organ at 0.1252). Split state, four zones, three points and crossfade widths are all modelled in artifact/src/system/program.ts and toggled from the panel Split button.
  • Layer handling is uneven: piano A/B have on/level/octave bindings, but organ layer B has no panel control at all, and synth layers 2 and 3 expose only a level fader — every oscillator, filter, envelope, LFO, voice and arp binding writes to synth.layers[0] only.
  • Layer Scenes produce no audible difference (Scene II 0.018920 vs Scene I 0.018877 on the split program) because the scene masks are empty in every factory program and the panel gives no way to author one.
  • Morph sources never reach their destinations in the running build. The morph-assign buttons are bound and the MORPHABLE destination table is complete, but System4.setWheel/setPedal are only ever called from tests, so moving the wheel on '5.5 Band Layered' (which ships two wheel assignments) changed the render by 0.17% — RMS 0.612934 to 0.613954.
Programs & Live Mode 3/4 75
  • 32 regular slots plus 8 Live slots are real and navigable from the panel: buttons 1-8 recall the factory programs by name in the OLED, Page up moves to P2.8 (empty-slot default 'A:001 Grand'), Page down returns to P1.8, and Live Mode switches the readout to LIVE with a separate slot set and returns cleanly.
  • Two-press Store round-trips: edit -> 'P1.1E' -> Store, Store -> 'P1.1' -> leave and return -> the stored Electric voice comes back (RMS 0.009740 against the original Grand 0.018915).
  • The dirty flag is truthful in both directions (appears only after a real control move, cleared by Store, discarded on program change).
  • Gaps: Store As has no panel entry point, the program name never changes on the OLED after an edit, and Live-slot auto-store could only be checked by reading artifact/src/audio/system4.ts rather than measured, because the Live slots all start from the same factory program.
